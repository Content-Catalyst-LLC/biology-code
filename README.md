# Biology Code

This repository supports the Biology knowledge series with reproducible computational workflows, simulations, models, data structures, and article-specific code.

Each article receives its own folder under:

articles/ARTICLE_SLUG/

The repository mirrors the structure used for the Physics code repository, with a full scientific-computing stack for each article.

## Standard Article Folder Structure

articles/article-slug/
├── README.md
├── python/
├── r/
├── julia/
├── fortran/
├── rust/
├── go/
├── c/
├── cpp/
├── sql/
├── docs/
├── data/
└── notebooks/

## Preferred Language Roles

- R: ecology, biodiversity analysis, biostatistics, population models, epidemiology, statistical graphics, and tidy biological data workflows.
- Python: computational biology, simulations, bioinformatics, machine learning, image analysis, geospatial workflows, and notebooks.
- Julia: high-performance scientific computing, differential equations, systems biology, ecological simulation, and numerical modeling.
- Fortran: legacy scientific computing, numerical ecology, population models, and ecosystem-model interfaces.
- Rust: safe command-line utilities, reproducible data tools, parsers, and performance-oriented workflows.
- Go: simple reproducible command-line tools, lightweight data utilities, workflow helpers, and portable executables.
- C: low-level numerical examples, embedded biological instrumentation, sensor workflows, and compact computational kernels.
- C++: performance-critical simulation, agent-based models, sequence algorithms, and large-scale ecological or evolutionary computation.
- SQL: biological metadata, observation records, species tables, sampling design, experiment logs, provenance, and reproducibility.
