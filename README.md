# Biology Code

This repository supports the Biology knowledge series with reproducible computational workflows, simulations, models, data structures, and article-specific code.

The repository mirrors the structure used for the Physics code repository. Each article receives its own folder under `articles/ARTICLE_SLUG/`, with language-specific and documentation subfolders for reproducible scientific work.

## Repository Purpose

The Biology code repository supports computational and analytical work across ecology, conservation biology, biodiversity science, population biology, evolutionary biology, genetics, genomics, molecular biology, cell biology, systems biology, microbiology, marine biology, freshwater biology, soil biology, plant science, agroecology, forestry, disease ecology, biostatistics, computational biology, bioinformatics, environmental biology, restoration ecology, and health-resilience systems.

## Article Folder Structure

Each article should use this structure:

articles/article-slug/
├── README.md
├── python/
├── r/
├── julia/
├── cpp/
├── fortran/
├── sql/
├── rust/
├── c/
├── docs/
├── data/
└── notebooks/

## Standard Article Repository Link

https://github.com/Content-Catalyst-LLC/biology-code/tree/main/articles/ARTICLE_SLUG

## Preferred Language Roles

- R: biostatistics, ecology, biodiversity analysis, population models, epidemiology, statistical graphics, and tidy biological data workflows.
- Python: computational biology, simulations, bioinformatics, machine learning, image analysis, geospatial workflows, and notebooks.
- Julia: high-performance scientific computing, differential equations, systems biology, ecological simulation, and numerical modeling.
- SQL: biological metadata, observation records, species tables, sampling design, experiment logs, provenance, and reproducibility.
- C++: performance-critical simulation, agent-based models, sequence algorithms, and large-scale ecological or evolutionary computation.
- Fortran: legacy scientific computing, population models, climate/ecosystem model interfaces, and numerical biology.
- Rust: safe command-line utilities, reproducible data tools, parsers, and performance-oriented workflows.
- C: low-level numerical examples, embedded biological instrumentation, sensor workflows, and compact computational kernels.
