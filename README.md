# Biology Code

This repository supports the Biology knowledge series with reproducible computational workflows, simulations, models, data structures, and article-specific code.

Each article receives its own folder under:

articles/ARTICLE_SLUG/

The repository mirrors the structure used for the Physics code repository.

## Standard Article Folder Structure

articles/article-slug/
├── README.md
├── python/
├── r/
├── julia/
├── cpp/
├── fortran/
├── sql/
├── rust/
├── c/
├── docs/
├── data/
└── notebooks/

## Preferred Language Roles

- R: ecology, biodiversity analysis, biostatistics, population models, epidemiology, and tidy biological data workflows.
- Python: computational biology, simulations, bioinformatics, machine learning, geospatial workflows, and notebooks.
- Julia: high-performance scientific computing, differential equations, systems biology, and ecological simulation.
- SQL: biological metadata, observations, sampling design, experiment logs, provenance, and reproducibility.
- C++: performance-critical simulation, agent-based models, and large-scale ecological or evolutionary computation.
- Fortran: legacy scientific computing and numerical biology.
- Rust: safe command-line utilities and reproducible data tools.
- C: low-level numerical examples, embedded instrumentation, and compact computational kernels.
