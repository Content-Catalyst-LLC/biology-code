# Repository Structure

This repository mirrors the Physics code repository pattern.

## Root-Level Folders

- `articles/` — article-specific computational workflows
- `templates/` — reusable article folder templates
- `shared/` — reusable utilities, helper functions, and shared biological datasets
- `docs/` — repository-level documentation
- `data/` — repository-level data scaffolding
- `notebooks/` — exploratory notebooks
