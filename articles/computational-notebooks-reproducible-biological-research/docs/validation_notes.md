# Validation Notes

Notebook validation should include both computational and scientific review.

## Computational Checks

- Does the notebook run from a clean kernel?
- Are all paths relative?
- Are required files present?
- Are package versions recorded?
- Are output artifacts regenerated?
- Are random seeds recorded when stochastic methods are used?
- Are hidden manual steps documented?
- Are data checksums available?

## Biological Checks

- Are biological units of analysis clear?
- Are sample identifiers unique?
- Are treatments, batches, sites, species, and time points documented?
- Are missing values summarized?
- Are units and measurement methods documented?
- Are sensitive data handled appropriately?
- Are conclusions limited to the evidence?

## Interpretation

Execution success is not scientific validity. Validation must include biological review, domain expertise, and appropriate external evidence.
