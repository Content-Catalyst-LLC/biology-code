# Responsible Use Notes

This repository is educational.

Do not use these scripts for clinical diagnosis, regulatory biotechnology decisions, patient stratification, conservation triage, environmental permitting, or automated biological risk assessment.

Responsible notebook sharing may require restricted data access when working with:

- human-derived biological data
- rare disease cohorts
- endangered species locations
- Indigenous or community-governed ecological knowledge
- sensitive environmental-health data
- conservation-risk information

When data cannot be public, researchers can still share synthetic examples, metadata schemas, code templates, environment files, provenance structures, and methodological documentation.
