# Reproducibility Notes

All datasets are synthetic and educational.

Reproducible biology-ethics workflows should preserve:

- project descriptions
- ethical dimension definitions
- benefit assumptions
- harm assumptions
- uncertainty assumptions
- consent criteria
- justice and equity criteria
- reversibility assumptions
- ecological risk assumptions
- governance notes
- code versions
- input data files
- output artifacts
- provenance records
- limitations and responsible-use notes

Future extensions could include:

- IRB-style checklist templates
- animal-care review metadata
- community-consultation records
- genomic data governance indicators
- biodiversity benefit-sharing templates
- AI model-card fields for biological systems
- ecological intervention risk registers
- consent-language readability analysis
- fairness audits for biological datasets
- stakeholder-impact matrices
- deliberative review documentation
