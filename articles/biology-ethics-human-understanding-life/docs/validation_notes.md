# Validation Notes

This repository is an educational scaffold.

## Computational Validation

- Check formulas.
- Check input ranges.
- Check that outputs are generated from code.
- Cross-check core calculations across languages.
- Record provenance for input data and outputs.

## Ethical Validation

Ethical review requires human judgment and institutional accountability. Useful evidence may include:

- scientific protocol review
- participant-risk review
- informed-consent review
- community consultation
- animal welfare review
- ecological risk assessment
- data governance review
- justice and equity analysis
- legal and regulatory review
- independent oversight

## Interpretation

Scores can make assumptions visible, but they cannot determine what is ethical. Responsible use requires deliberation, expertise, accountability, and context.
