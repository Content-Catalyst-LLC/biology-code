# Responsible Use Notes

This repository is educational.

Do not use these scripts for:

- institutional review board decisions
- animal-care approvals
- clinical ethics decisions
- regulatory submissions
- consent approval
- biodiversity permitting
- ecological release decisions
- genomic-data access control
- automated moral judgment
- compliance certification

Responsible biology ethics requires institutional review, human deliberation, community participation, legal compliance, domain expertise, and accountable governance.
