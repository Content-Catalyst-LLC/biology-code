# Notebook Workflow

Suggested notebook sections:

1. Load FASTA sequences.

4. Detect simple ORFs.
5. Translate simple ORFs.
6. Summarize FASTQ-style quality scores.
7. Validate variant table and calculate VAF.
8. Validate metadata.
9. Query SQL provenance structures.
10. Record limitations and session information.
