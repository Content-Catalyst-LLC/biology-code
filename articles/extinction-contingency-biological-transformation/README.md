# Extinction, Contingency, and Biological Transformation

This article repository supports the Biology knowledge-series article:

**Extinction, Contingency, and Biological Transformation**

The code distribution expands the article's compact R and Python examples into a fuller computational extinction workflow. It includes survivorship proportions, extinction proportions, hazard screening, stochastic crisis survivorship, post-crisis recovery, trait-dependent vulnerability, phylogenetic-loss scoring, conservation condition screening, SQL provenance structures, reproducible data files, and multi-language scientific-computing scaffolding.

## Repository Structure

- `python/` — clade loss comparison, stochastic survivorship, recovery trajectories, trait-risk screening, and phylogenetic-loss scoring
- `r/` — survivorship comparison, hazard screening, post-crisis recovery, and extinction-risk screening
- `julia/` — extinction hazard and recovery modeling
- `fortran/` — compact survivorship and recovery numerical kernels
- `rust/` — safe command-line extinction-risk scoring utility
- `go/` — portable extinction condition scoring helper
- `c/` — survivorship and recovery computational kernel
- `cpp/` — comparative extinction scenario simulation
- `sql/` — clades, hazards, recovery scenarios, trait-risk data, outputs, and provenance schema
- `docs/` — setup, methodology, and reproducibility notes
- `data/` — small reproducible example datasets
- `notebooks/` — notebook scaffold and workflow notes

## Scientific Focus

The workflows are designed to support transparent extinction and historical-biology reasoning:

1. Compare survivorship and extinction proportions across clades.
2. Model survivorship under different extinction hazards.
3. Simulate stochastic crisis survivorship.
4. Compare post-crisis recovery trajectories.
5. Screen trait-dependent vulnerability.
6. Estimate simplified phylogenetic-loss fractions.
7. Track data provenance and reproducibility.

These examples are educational scaffolds, not operational conservation, paleobiological, phylogenetic, or extinction-risk models. Real applications require fossil occurrence data, phylogenetic structure, preservation analysis, empirical abundance or range data, uncertainty analysis, and expert interpretation.
