# Notebook Workflow

The notebook scaffold demonstrates how to connect survivorship proportions, extinction proportions, hazard screening, stochastic survivorship, post-crisis recovery, trait-dependent risk, phylogenetic-loss scoring, condition scoring, and provenance documentation.

Suggested notebook sections:

1. Load clade survivorship data.
2. Calculate survivorship and extinction proportions.
3. Compare hazard scenarios.
4. Simulate stochastic survivorship.
5. Compare post-crisis recovery trajectories.
6. Score trait-dependent risk.
7. Estimate simplified phylogenetic-loss fraction.
8. Record provenance and limitations.

The included `.ipynb` file is intentionally minimal so it can be opened and expanded in JupyterLab or VS Code.
