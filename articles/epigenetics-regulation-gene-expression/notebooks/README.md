# Notebook Workflow

The notebook scaffold demonstrates how to connect transcript decay, production-decay dynamics, two-state regulatory switching, methylation fractions, expression/accessibility concordance, cell-state transitions, epigenetic condition scoring, and provenance documentation.

Suggested notebook sections:

1. Load expression time course.
2. Estimate decay constant, half-life, and area under the curve.
3. Load methylation counts and calculate methylation fractions.
4. Compare expression and chromatin accessibility change.
5. Simulate two-state regulatory switching.
6. Simulate cell-state transitions.
7. Score epigenetic condition examples.
8. Record provenance and limitations.

The included `.ipynb` file is intentionally minimal so it can be opened and expanded in JupyterLab or VS Code.
