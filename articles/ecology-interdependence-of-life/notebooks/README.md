# Notebook Workflow

The notebook scaffold demonstrates how to connect community composition, turnover, ecosystem indicators, network connectance, ecological-condition screening, and provenance documentation.

Suggested notebook sections:

1. Load the site-by-species matrix.
2. Calculate Shannon diversity and Bray-Curtis turnover.
3. Join ecosystem process indicators.
4. Calculate ecological-condition scores.
5. Load an interaction matrix and calculate connectance.
6. Record provenance and limitations.

The included `.ipynb` file is intentionally minimal so it can be opened and expanded in JupyterLab or VS Code.
