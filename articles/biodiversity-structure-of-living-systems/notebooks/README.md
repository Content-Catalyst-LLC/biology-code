# Notebook Workflow

The notebook scaffold demonstrates how to connect biodiversity metrics, turnover, trait summaries, priority screening, and provenance documentation.

Suggested notebook sections:

1. Load the site-by-species matrix.
2. Calculate richness, Shannon, Simpson, and Hill numbers.
3. Compute Bray-Curtis turnover among sites.
4. Join trait data and calculate community-weighted means.
5. Screen biodiversity priority under fragmentation pressure.
6. Record provenance and limitations.

The included `.ipynb` file is intentionally minimal so it can be opened and expanded in JupyterLab or VS Code.
