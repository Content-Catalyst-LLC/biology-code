# Validation Notes

This repository is an educational scaffold.

## Computational Validation

- Check formulas.
- Check input ranges.
- Check that frequencies remain between 0 and 1.
- Check that outputs are generated from code.
- Cross-check core calculations across languages.
- Record provenance for input data and outputs.

## Scientific Validation

Evolutionary medicine explanations require evidence. Useful evidence may include:

- mechanistic biology
- comparative biology
- phylogenetic evidence
- epidemiological patterns
- experimental data
- population genetics
- pathogen evolution data
- longitudinal data
- clinical data
- ecological evidence

## Interpretation

Evolutionary explanations do not replace clinical judgment. They should not be used to justify suffering, inequality, stigma, or deterministic claims.
