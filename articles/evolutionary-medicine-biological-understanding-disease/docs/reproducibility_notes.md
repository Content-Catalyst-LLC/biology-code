# Reproducibility Notes

All datasets are synthetic and educational.

Reproducible evolutionary medicine workflows should preserve:

- disease scenario definitions
- evolutionary mechanism categories
- parameter assumptions
- selection coefficients
- exposure definitions
- time-step definitions
- code versions
- input data files
- output artifacts
- provenance records
- limitations and responsible-use notes

Future extensions could include:

- stochastic antimicrobial resistance simulations
- agent-based pathogen transmission
- cancer clonal evolution models
- adaptive therapy simulations
- host-pathogen coevolution models
- life-history sensitivity analysis
- Bayesian evolutionary parameter estimation
- phylogenetic disease modeling
- One Health surveillance metadata
- environmental mismatch indicators
