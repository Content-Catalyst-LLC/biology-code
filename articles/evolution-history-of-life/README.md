# Evolution and the History of Life

This article repository supports the Biology knowledge-series article:

**Evolution and the History of Life**

The code distribution expands the article's compact R and Python examples into a fuller computational evolution workflow. It includes allele-frequency evolution, Hardy-Weinberg baselines, genotype-specific selection, bidirectional mutation, migration, Wright-Fisher drift, sequence divergence, Jukes-Cantor distance, distance matrices, exploratory clustering inputs, birth-death diversification, lineage-through-time screening, major-transition documentation, evolutionary condition scoring, SQL provenance structures, reproducible data files, and multi-language scientific-computing scaffolding.

## Repository Structure

- `python/` — allele-frequency evolution, Wright-Fisher replicates, sequence-distance matrices, birth-death screening, and evolutionary condition scoring
- `r/` — selection-mutation-migration-drift simulation, sequence divergence, birth-death lineage-through-time screening, and evolutionary summaries
- `julia/` — allele-frequency, distance, diversification, and transition modeling
- `fortran/` — compact evolutionary numerical kernels
- `rust/` — safe command-line evolutionary condition scoring utility
- `go/` — portable evolutionary condition scoring helper
- `c/` — allele-frequency, sequence-distance, and diversification computational kernel
- `cpp/` — comparative evolutionary scenario simulation
- `sql/` — evolutionary scenarios, sequence data, diversification scenarios, major transitions, outputs, and provenance schema
- `docs/` — setup, methodology, and reproducibility notes
- `data/` — small reproducible example datasets
- `notebooks/` — notebook scaffold and workflow notes

## Scientific Focus

The workflows are designed to support transparent evolutionary reasoning:

1. Model allele-frequency change under selection, mutation, migration, and drift.
2. Calculate Hardy-Weinberg expectations and heterozygosity.
3. Simulate Wright-Fisher evolutionary trajectories across replicates.
4. Calculate sequence divergence and Jukes-Cantor distances.
5. Build distance matrices for exploratory comparative workflows.
6. Simulate birth-death diversification and lineage richness.
7. Document major transitions and evolutionary condition scoring.
8. Track data provenance and reproducibility.

These examples are educational scaffolds, not operational phylogenetic, paleobiological, conservation, biomedical, or genomic inference models. Real applications require empirical data, explicit model assumptions, uncertainty analysis, and expert interpretation.
