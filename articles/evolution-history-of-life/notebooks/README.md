# Notebook Workflow

The notebook scaffold demonstrates how to connect allele-frequency evolution, Hardy-Weinberg expectations, selection, mutation, migration, drift, sequence distance, birth-death diversification, major transitions, evolutionary condition scoring, and provenance documentation.

Suggested notebook sections:

1. Load evolutionary scenarios.
2. Calculate genotype expectations.
3. Simulate selection, mutation, migration, and drift.
4. Load aligned sequences and calculate distance matrices.
5. Compare birth-death diversification scenarios.
6. Review major transitions.
7. Score evolutionary condition examples.
8. Record provenance and limitations.

The included `.ipynb` file is intentionally minimal so it can be opened and expanded in JupyterLab or VS Code.
