# Validation Notes

This repository is an educational scaffold.

## Computational Validation

- Check formulas.
- Check input ranges.
- Check that outputs are generated from code.
- Cross-check core calculations across languages.
- Record provenance for input data and outputs.

## Scientific Validation

Agriculture and food-system indicators require evidence. Useful evidence may include:

- field measurements
- soil tests
- water-use records
- nutrient-management records
- remote sensing
- household dietary surveys
- farm-management records
- biodiversity monitoring
- climate data
- supply-chain data
- community and farmer knowledge

## Interpretation

Food-system indicators are not neutral. Indicator choice reflects values, scale, and governance priorities. Interpret outputs with ecological, nutritional, social, and justice context.
