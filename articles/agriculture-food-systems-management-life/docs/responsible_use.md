# Responsible Use Notes

This repository is educational.

Do not use these scripts for:

- farm-management prescriptions
- food-security forecasting
- nutrition diagnosis
- climate-risk decisions
- regulatory compliance
- subsidy allocation
- land-use permitting
- automated sustainability certification
- public-health targeting

Responsible agriculture and food-system analysis requires local context, empirical data, farmer and community knowledge, ecological expertise, public-health expertise, and governance review.
