# Reproducibility Notes

All datasets are synthetic and educational.

Reproducible agriculture and food-system workflows should preserve:

- production-system definitions
- crop and livestock categories
- spatial and temporal scale
- soil and water measurement methods
- nutrient-input assumptions
- food-loss definitions
- diet-diversity assumptions
- biodiversity indicator definitions
- code versions
- input data files
- output artifacts
- provenance records
- limitations and responsible-use notes

Future extensions could include:

- geospatial food-system layers
- crop-climate scenario analysis
- soil organic carbon uncertainty intervals
- nutrient-flow balance models
- livestock methane scenario models
- food-access mapping
- farm-level biodiversity monitoring
- agroecological transition indicators
- true-cost accounting scaffolds
- participatory data governance templates
- food-system resilience dashboards
