# Notebook Workflow

The notebook scaffold demonstrates how to connect population divergence, FST-style structure, sequence distance, Jukes-Cantor correction, birth-death diversification, speciation condition scoring, and provenance documentation.

Suggested notebook sections:

1. Load divergence scenarios.
2. Simulate divergence between two populations under limited migration.
3. Calculate mean allele-frequency divergence and FST-style structure.
4. Load aligned sequences and calculate a distance matrix.
5. Run birth-death diversification screening.
6. Score speciation condition examples.
7. Record provenance and limitations.

The included `.ipynb` file is intentionally minimal so it can be opened and expanded in JupyterLab or VS Code.
