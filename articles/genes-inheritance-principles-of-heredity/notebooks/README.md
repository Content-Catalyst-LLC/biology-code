# Notebook Workflow

The notebook scaffold demonstrates how to connect genotype expectations, allele frequencies, chi-square tests, recombination fractions, quantitative-trait variance, heredity condition scoring, and provenance documentation.

Suggested notebook sections:

1. Load genotype counts.
2. Estimate allele frequencies and expected heterozygosity.
3. Load monohybrid and dihybrid ratio tests.
4. Calculate expected counts and chi-square components.
5. Load recombination observations and estimate recombination fraction.
6. Load quantitative trait records and calculate simple heritability scaffold.
7. Score heredity condition examples.
8. Record provenance and limitations.

The included `.ipynb` file is intentionally minimal so it can be opened and expanded in JupyterLab or VS Code.
