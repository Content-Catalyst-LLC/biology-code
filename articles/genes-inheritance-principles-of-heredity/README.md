# Genes, Inheritance, and the Principles of Heredity

This article repository supports the Biology knowledge-series article:

**Genes, Inheritance, and the Principles of Heredity**

The code distribution expands the article's compact R and Python examples into a fuller computational heredity workflow. It includes Mendelian genotype expectations, monohybrid and dihybrid simulations, chi-square goodness-of-fit testing, allele-frequency estimation, Hardy-Weinberg expectations, expected heterozygosity, linkage and recombination simulations, quantitative trait and heritability scaffolds, pedigree-style inheritance logic, conservation-genetic condition scoring, SQL provenance structures, reproducible data files, and multi-language scientific-computing scaffolding.

## Repository Structure

- `python/` — genotype expectations, chi-square testing, inheritance simulation, recombination, allele frequencies, quantitative traits, and heredity condition scoring
- `r/` — Mendelian expectations, chi-square testing, monohybrid/dihybrid simulations, linkage, and quantitative-genetics scaffolds
- `julia/` — heredity probability, genotype frequencies, recombination, heritability, and selection-response calculations
- `fortran/` — compact heredity numerical kernels
- `rust/` — safe command-line heredity condition scoring utility
- `go/` — portable heredity condition scoring helper
- `c/` — allele frequency, genotype expectation, recombination, and chi-square computational kernel
- `cpp/` — comparative heredity scenario simulation
- `sql/` — crosses, genotype counts, recombination observations, quantitative trait records, condition scores, outputs, and provenance schema
- `docs/` — setup, methodology, and reproducibility notes
- `data/` — small reproducible example datasets
- `notebooks/` — notebook scaffold and workflow notes

## Scientific Focus

The workflows are designed to support transparent heredity reasoning:

1. Calculate Mendelian genotype expectations.
2. Test inheritance ratios using chi-square logic.
3. Simulate monohybrid and dihybrid crosses.
4. Estimate allele frequencies from genotype counts.
5. Estimate expected heterozygosity.
6. Simulate linkage and recombination.
7. Partition additive and phenotypic variance in a quantitative-trait scaffold.
8. Score heredity and conservation-genetic condition examples.
9. Track data provenance and reproducibility.

These examples are educational scaffolds, not operational clinical-genetics, breeding, conservation-genomics, pedigree-analysis, or population-genomics pipelines. Real applications require empirical data, quality control, experimental design, statistical inference, uncertainty analysis, and expert interpretation.
