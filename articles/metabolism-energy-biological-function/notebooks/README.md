# Notebook Workflow

The notebook scaffold demonstrates how to connect growth fitting, yield estimation, allocation balances, respirometry, Monod substrate limitation, toy flux-balance logic, metabolic condition scoring, and provenance documentation.

Suggested notebook sections:

1. Load growth observations.
2. Fit exponential growth by condition.
3. Estimate doubling time.
4. Simulate logistic growth.
5. Load substrate-biomass observations and estimate biomass yield.
6. Load energy-budget scenarios and check mass balance.
7. Summarize oxygen-consumption observations.
8. Run a toy flux-balance search.
9. Score metabolic condition examples.
10. Record provenance and limitations.

The included `.ipynb` file is intentionally minimal so it can be opened and expanded in JupyterLab or VS Code.
