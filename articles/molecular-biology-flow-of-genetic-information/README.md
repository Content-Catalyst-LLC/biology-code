# Molecular Biology and the Flow of Genetic Information

This article repository supports the Biology knowledge-series article:

**Molecular Biology and the Flow of Genetic Information**

The code distribution expands the article's compact R and Python examples into a fuller computational molecular-biology workflow. It includes transcript-decay fitting, production-decay expression dynamics, half-life estimation, expression matrices, log2 fold change, PCA-style ordination, sequence comparison, Jukes-Cantor correction, GC-content calculation, codon-usage summaries, DNA-to-protein translation scaffolds, mutation-rate examples, molecular-information-flow scoring, SQL provenance structures, reproducible data files, and multi-language scientific-computing scaffolding.

## Repository Structure

- `python/` — transcript dynamics, sequence comparison, expression matrices, codon usage, translation, mutation-rate examples, and molecular-flow scoring
- `r/` — transcript decay, expression matrix summaries, codon usage, GC content, and sequence comparison
- `julia/` — transcript decay, sequence distance, GC fraction, codon frequency, mutation-rate, and expression calculations
- `fortran/` — compact molecular biology numerical kernels
- `rust/` — safe command-line molecular information-flow scoring utility
- `go/` — portable molecular information-flow scoring helper
- `c/` — sequence, GC, transcript half-life, mutation-rate, and expression computational kernel
- `cpp/` — comparative molecular-information-flow scenario simulation
- `sql/` — sequence records, transcript observations, expression observations, codon counts, condition scores, outputs, and provenance schema
- `docs/` — setup, methodology, and reproducibility notes
- `data/` — small reproducible example datasets
- `notebooks/` — notebook scaffold and workflow notes

## Scientific Focus

The workflows are designed to support transparent molecular-biology reasoning:

1. Estimate transcript decay constants and half-lives.
2. Simulate production-decay expression dynamics.
3. Compare DNA sequences with Hamming and Jukes-Cantor distances.
4. Calculate GC fraction and codon usage.
5. Translate a compact coding sequence into a protein scaffold.
6. Summarize expression matrices with log2 fold change and PCA-style ordination.
7. Estimate a simple mutation rate from observed counts.
8. Score molecular information-flow examples.
9. Track data provenance and reproducibility.

These examples are educational scaffolds, not operational sequencing, transcriptomics, clinical diagnostics, regulatory-genomics, phylogenetic, or molecular-diagnostics pipelines. Real applications require empirical data, quality control, annotation, statistical modeling, uncertainty analysis, and expert interpretation.
