# Validation Notes

This repository is an educational scaffold.

## Computational Validation

- Check formulas.
- Check input ranges.
- Check that outputs are generated from code.
- Check provenance manifests.
- Cross-check core calculations across languages.

## Experimental Validation

Synthetic biology designs require:

- sequence verification
- replicate experiments
- calibrated measurements
- strain and construct documentation
- growth-condition documentation
- burden assessment
- stability assessment
- off-target or unintended effect analysis when applicable
- biosafety review
- external replication where possible

## Interpretation

A numerical engineering score is not proof that a biological design is safe, scalable, stable, or useful. Scores can help organize assumptions, but biological designs require experimental validation and expert review.
