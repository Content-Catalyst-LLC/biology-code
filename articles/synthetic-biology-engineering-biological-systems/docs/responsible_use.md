# Responsible Use Notes

This repository is educational.

Do not use these scripts for:

- constructing biological organisms
- biosafety approvals
- environmental release decisions
- clinical or therapeutic decisions
- biosecurity screening
- regulatory submissions
- industrial process control
- automated risk classification
- ecological permitting

Responsible synthetic biology requires domain expertise, institutional oversight, legal compliance, biosafety assessment, biosecurity review, measurement standards, public accountability, and appropriate governance.
