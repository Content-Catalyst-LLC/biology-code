# Notebook Workflow

The notebook scaffold demonstrates how to connect habitat predictors, species-area modeling, habitat suitability, spatial prioritization, and provenance documentation.

Suggested notebook sections:

1. Load habitat-site data.
2. Fit a compact habitat-suitability model.
3. Rank sites by suitability and connectivity.
4. Fit species-area relationships.
5. Compare fragmentation scenarios.
6. Record provenance and limitations.

The included `.ipynb` file is intentionally minimal so it can be opened and expanded in JupyterLab or VS Code.
