# Reproducibility Notes

All data in this repository are synthetic and educational. The repository demonstrates reproducible structure for probability and biological inference workflows.

Future extensions could include:

- generalized linear models
- mixed-effects models
- Bayesian hierarchical inference
- survival models
- occupancy models
- detection probability models
- phylogenetic uncertainty
- compositional data workflows
- false discovery rate analysis at genomic scale
- containerized environments
- CI validation for all scripts
