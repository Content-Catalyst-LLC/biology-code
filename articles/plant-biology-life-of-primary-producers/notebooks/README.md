# Notebook Workflow

The notebook scaffold demonstrates how to connect plant productivity, carbon balance, light response, biomass recovery, condition scoring, and provenance documentation.

Suggested notebook sections:

1. Load productivity site data.
2. Calculate NPP and NEP.
3. Simulate light-response curves under drought and nutrient limitation.
4. Simulate biomass recovery after disturbance.
5. Score plant condition across sites.
6. Record provenance and limitations.

The included `.ipynb` file is intentionally minimal so it can be opened and expanded in JupyterLab or VS Code.
