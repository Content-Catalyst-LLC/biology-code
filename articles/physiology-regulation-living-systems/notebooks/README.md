# Notebook Workflow

The notebook scaffold demonstrates how to connect regulated variables, hormonal signaling, effector response, feedback scenarios, regulatory performance, condition scoring, and provenance documentation.

Suggested notebook sections:

1. Load feedback scenarios and thresholds.
2. Simulate coupled physiological regulation.
3. Compare peak regulated variable, peak signal, peak effector response, and recovery error.
4. Classify scenarios using illustrative thresholds.
5. Calculate physiological condition scores.
6. Record provenance and limitations.

The included `.ipynb` file is intentionally minimal so it can be opened and expanded in JupyterLab or VS Code.
