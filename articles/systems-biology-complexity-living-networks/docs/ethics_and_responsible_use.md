# Ethics and Responsible Use

This repository is educational.

Do not use these scripts for clinical decision-making, patient stratification, therapeutic targeting, diagnostic interpretation, regulatory biotechnology decisions, or automated biological risk assessment.

Responsible systems biology requires:

- biological expertise
- documented data provenance
- database-version documentation
- model validation
- uncertainty communication
- privacy and governance review for human-derived data
- careful distinction between correlation, interaction, mechanism, and causality
- review by domain experts

Models can support scientific reasoning, but they should not replace biological or clinical judgment.
