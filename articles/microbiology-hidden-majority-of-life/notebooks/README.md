# Notebook Workflow

The notebook scaffold demonstrates how to connect logistic growth, Monod kinetics, environmental modifiers, community recovery, microbial condition scoring, uncertainty screening, and provenance documentation.

Suggested notebook sections:

1. Load growth environments.
2. Calculate environmental growth modifiers.
3. Simulate logistic population trajectories.
4. Load Monod scenarios and simulate substrate-limited growth.
5. Simulate community recovery after disturbance.
6. Score microbial condition for applied site screening.
7. Record provenance and limitations.

The included `.ipynb` file is intentionally minimal so it can be opened and expanded in JupyterLab or VS Code.
