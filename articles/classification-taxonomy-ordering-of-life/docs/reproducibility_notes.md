# Reproducibility Notes

All data in this repository are synthetic and educational. The repository demonstrates reproducible structure for taxonomy, systematics, biodiversity informatics, and ecological classification workflows.

Future extensions could include:

- FASTA parsing
- ambiguous-base handling
- voucher specimen metadata
- GBIF API export formatting
- phylogenetic tree files
- barcode gap summaries
- occurrence cleaning
- geospatial validation
- confidence intervals
- uncertainty propagation
