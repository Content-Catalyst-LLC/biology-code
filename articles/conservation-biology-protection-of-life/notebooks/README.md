# Notebook Workflow

The notebook scaffold demonstrates how to connect population viability analysis, conservation priority scoring, and provenance documentation.

Suggested notebook sections:

1. Load conservation-unit data.
2. Run priority scoring.
3. Run stochastic population viability scenarios.
4. Compare sensitivity to weights and assumptions.
5. Export tables and figures.
6. Record provenance and limitations.

The included `.ipynb` file is intentionally minimal so it can be opened and expanded in JupyterLab or VS Code.
