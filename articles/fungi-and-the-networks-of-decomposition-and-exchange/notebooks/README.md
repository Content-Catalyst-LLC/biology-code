# Notebook Workflow

The notebook scaffold demonstrates how to connect decomposition kinetics, environmental modifiers, fungal guilds, biomass recovery, network efficiency, restoration-priority screening, and provenance documentation.

Suggested notebook sections:

1. Load decomposition site scenarios.
2. Calculate temperature, moisture, substrate-quality, and guild modifiers.
3. Simulate remaining mass and carbon release.
4. Simulate fungal biomass recovery under intervention scenarios.
5. Build mycelial network adjacency matrices and calculate global efficiency.
6. Score restoration priority.
7. Record provenance and limitations.

The included `.ipynb` file is intentionally minimal so it can be opened and expanded in JupyterLab or VS Code.
