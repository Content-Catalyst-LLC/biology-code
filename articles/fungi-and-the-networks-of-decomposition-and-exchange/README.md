# Fungi and the Networks of Decomposition and Exchange

This article repository supports the Biology knowledge-series article:

**Fungi and the Networks of Decomposition and Exchange**

The code distribution expands the article's compact R and Python examples into a fuller computational fungal-biology workflow. It includes decomposition kinetics, temperature and moisture modifiers, substrate-quality effects, fungal guild scenarios, mycorrhizal cost-benefit logic, fungal biomass recovery, network-fragility analysis, restoration-priority scoring, SQL provenance structures, reproducible data files, and multi-language scientific-computing scaffolding.

## Repository Structure

- `python/` — stochastic decomposition, biomass recovery, network damage, and restoration screening
- `r/` — decomposition scenario analysis and fungal condition scoring
- `julia/` — fungal decomposition and biomass recovery modeling
- `fortran/` — compact decomposition and biomass numerical kernels
- `rust/` — safe command-line fungal condition scoring utility
- `go/` — portable fungal recovery scoring helper
- `c/` — decomposition and Q10 computational kernel
- `cpp/` — mycelial network efficiency simulation
- `sql/` — fungal sites, guilds, scenarios, model outputs, and provenance schema
- `docs/` — setup, methodology, and reproducibility notes
- `data/` — small reproducible example datasets
- `notebooks/` — notebook scaffold and workflow notes

## Scientific Focus

The workflows are designed to support transparent fungal-biology reasoning:

1. Model litter decomposition under temperature, moisture, substrate-quality, and fungal-guild modifiers.
2. Compare fungal functional scenarios across reference, degraded, and restored sites.
3. Simulate fungal biomass recovery after disturbance and inoculation.
4. Evaluate simple mycelial network efficiency under connection loss.
5. Score fungal condition and restoration priority using transparent indicators.
6. Track data provenance and reproducibility.

These examples are educational scaffolds, not operational ecosystem or clinical fungal models. Real applications require calibrated field data, taxonomic validation, functional trait evidence, uncertainty analysis, site context, and expert interpretation.
