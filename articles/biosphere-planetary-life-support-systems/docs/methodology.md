# Methodology Notes

## Purpose

The computational examples support biosphere-scale reasoning by turning article concepts into transparent calculations. The examples are intentionally compact so they can be inspected, adapted, and extended.

## Core Methods

### Biosphere Carbon Balance

The carbon-balance examples use a simplified stock-flow structure:

net atmospheric increment = anthropogenic emissions + disturbance release - land uptake - ocean uptake

This is not a full carbon-cycle model. It is a transparent scaffold for reasoning about biosphere-mediated carbon outcomes.

### Functional Integrity Screening

The functional-integrity examples combine normalized indicators:

- primary production
- water regulation
- nutrient retention
- habitat complexity
- ecological connectivity
- biodiversity signal
- disturbance pressure

Disturbance pressure is treated as a negative term.

### Disturbance Scenario Analysis

Several scripts compare baseline conditions against increased disturbance. This represents stressors such as wildfire, drought, land-use change, invasive species pressure, heat stress, or hydrological disruption.

## Interpretation

These workflows should be interpreted as educational decision-support scaffolds, not as operational Earth-system models. Real biosphere analysis requires validated data, uncertainty analysis, ecological expertise, remote-sensing calibration, and careful attention to spatial and temporal scale.
