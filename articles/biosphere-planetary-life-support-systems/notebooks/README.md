# Notebook Workflow

The notebook scaffold demonstrates how to connect biosphere indicators, functional-integrity scoring, carbon-balance scenarios, and provenance documentation.

Suggested notebook sections:

1. Load biosphere-unit indicators.
2. Calculate functional-integrity scores.
3. Run disturbance-pressure sensitivity analysis.
4. Compare carbon-balance scenarios.
5. Export tables and figures.
6. Record provenance and limitations.

The included `.ipynb` file is intentionally minimal so it can be opened and expanded in JupyterLab or VS Code.
