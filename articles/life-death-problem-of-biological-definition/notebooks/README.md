# Notebook Workflow

The notebook scaffold demonstrates how to connect viability decay, dormancy, host-virus dynamics, life-criteria scoring, borderline-case comparison, and provenance documentation.

Suggested notebook sections:

1. Load viability observations and fit decay rates.
2. Estimate viability half-life.
3. Simulate dormancy loss and reactivation.
4. Simulate host-virus dynamics.
5. Score borderline cases with explicit criteria and weights.
6. Record provenance and limitations.

The included `.ipynb` file is intentionally minimal so it can be opened and expanded in JupyterLab or VS Code.
