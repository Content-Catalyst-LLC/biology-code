# Notebook Workflow

The notebook scaffold demonstrates how to connect context-dependent mutualism, reciprocal feedback, host-pathogen dynamics, network dependency scoring, condition scoring, and provenance documentation.

Suggested notebook sections:

1. Load benefit-cost scenarios.
2. Calculate relationship-state thresholds.
3. Simulate reciprocal frequency dynamics.
4. Simulate host-pathogen infection pressure.
5. Score mutualistic network dependency risk.
6. Score symbiosis condition across sites.
7. Record provenance and limitations.

The included `.ipynb` file is intentionally minimal so it can be opened and expanded in JupyterLab or VS Code.
