# Coevolution, Symbiosis, and the Dynamics of Mutual Change

This article repository supports the Biology knowledge-series article:

**Coevolution, Symbiosis, and the Dynamics of Mutual Change**

The code distribution expands the article's compact R and Python examples into a fuller computational coevolution workflow. It includes partner-frequency dynamics, benefit-cost threshold screening, reciprocal frequency change, host-pathogen arms-race simulation, mutualistic network dependency scoring, relationship-state classification, SQL provenance structures, reproducible data files, and multi-language scientific-computing scaffolding.

## Repository Structure

- `python/` — benefit-cost thresholds, host-pathogen dynamics, network dependency scoring, and reciprocal feedback
- `r/` — context-dependent mutualism, reciprocal frequency dynamics, and interaction-risk screening
- `julia/` — coevolution payoff and host-pathogen dynamics modeling
- `fortran/` — compact reciprocal feedback and benefit-cost numerical kernels
- `rust/` — safe command-line symbiosis condition scoring utility
- `go/` — portable coevolution risk scoring helper
- `c/` — benefit-cost and infection-pressure computational kernel
- `cpp/` — comparative coevolution scenario simulation
- `sql/` — interaction scenarios, partners, network edges, outputs, and provenance schema
- `docs/` — setup, methodology, and reproducibility notes
- `data/` — small reproducible example datasets
- `notebooks/` — notebook scaffold and workflow notes

## Scientific Focus

The workflows are designed to support transparent coevolution and symbiosis reasoning:

1. Model context-dependent shifts from beneficial to costly association.
2. Simulate reciprocal frequency change between host and symbiont traits.
3. Simulate simple host-pathogen defense and escape dynamics.
4. Score dependency risk in mutualistic interaction networks.
5. Classify relationship states under environmental stress.
6. Track data provenance and reproducibility.

These examples are educational scaffolds, not operational disease, conservation, phylogenetic, or symbiosis models. Real applications require field data, genomic evidence, interaction measurements, uncertainty analysis, ecological context, and expert interpretation.
