# Notebook Workflow

The notebook scaffold demonstrates how to connect reservoir fluxes, habitability-support indicators, dissolved-oxygen stress, and provenance documentation.

Suggested notebook sections:

1. Load habitability-support indicators.
2. Calculate composite support scores.
3. Run oxygen-stress screening.
4. Compare nutrient-loading scenarios.
5. Inspect reservoir and flux tables.
6. Record provenance and limitations.

The included `.ipynb` file is intentionally minimal so it can be opened and expanded in JupyterLab or VS Code.
