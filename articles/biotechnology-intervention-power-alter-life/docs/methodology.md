# Methodology Notes

## Purpose

This repository demonstrates reproducible computational scaffolding for thinking about biotechnology intervention.

## Intervention Dimensions

The synthetic workflow uses the following conceptual dimensions:

- expected benefit
- expected harm
- uncertainty
- reversibility
- access equity
- environmental exposure
- governance readiness
- containment strength

These are educational scoring dimensions, not validated regulatory metrics.

## Containment

The containment calculation estimates the probability that at least one containment layer fails. The simplified formula assumes independent failures. Real containment systems may have correlated failures and require facility-specific expert review.

## Equity

Equity-adjusted access is calculated as:

equity_adjusted_access = nominal_availability * (1 - inequality_penalty)

This is a conceptual scaffold for discussing access, not a formal health-economics or justice metric.

## Ecological Release

Ecological release scenarios are scored using exposure, magnitude, and uncertainty. Real ecological biotechnology assessment requires empirical evidence, modeling, monitoring, community engagement, and regulatory review.
