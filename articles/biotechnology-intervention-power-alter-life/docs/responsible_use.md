# Responsible Use Notes

This repository is educational.

Do not use these scripts for:

- clinical decisions
- regulatory submissions
- biosafety approvals
- environmental release decisions
- gene-drive release assessment
- biosecurity screening
- therapeutic development decisions
- agricultural biotechnology deployment
- ecological permitting
- automated risk classification

Responsible biotechnology requires domain expertise, institutional oversight, legal compliance, risk assessment, community engagement, transparency, public accountability, and appropriate governance.
