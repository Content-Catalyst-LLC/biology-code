# Validation Notes

This repository is an educational scaffold.

## Computational Validation

- Check formulas.
- Check input ranges.
- Check that outputs are generated from code.
- Check that provenance manifests include input artifacts.
- Cross-check core calculations across languages.

## Scientific Validation

- Intervention scores require expert-defined criteria.
- Risk and benefit dimensions require empirical evidence.
- Ecological release requires ecological modeling and monitoring.
- Clinical applications require clinical evidence and regulatory review.
- Biosecurity applications require specialized review and access controls.

## Interpretation

A numerical score is not a biotechnology decision. Scores can help organize assumptions, but decisions require expert review, governance, ethics, community engagement, and legal compliance.
