# Notebook Workflow

The notebook scaffold demonstrates how to connect behavioral options, utility scoring, softmax choice, signaling strategies, receiver response, environmental noise, and conflict modeling.

Suggested notebook sections:

1. Load behavioral option data.
2. Calculate utility and softmax choice probabilities.
3. Compare baseline and high-predation scenarios.
4. Load signaling strategies.
5. Calculate sender utility, receiver response, and combined score.
6. Simulate noisy-environment signal degradation.
7. Compare Hawk-Dove conflict scenarios.
8. Record provenance and limitations.

The included `.ipynb` file is intentionally minimal so it can be opened and expanded in JupyterLab or VS Code.
