# Notebook Workflow

The notebook scaffold demonstrates how to connect allometric scaling, metabolic demand, population recovery, survival screening, stage projection, condition scoring, and provenance documentation.

Suggested notebook sections:

1. Load species trait data.
2. Calculate allometric metabolic rate and mass-specific demand.
3. Simulate logistic recovery scenarios.
4. Compare survival under hazard scenarios.
5. Project juvenile-adult stage structure.
6. Score animal condition across sites.
7. Record provenance and limitations.

The included `.ipynb` file is intentionally minimal so it can be opened and expanded in JupyterLab or VS Code.
