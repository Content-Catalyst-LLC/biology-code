# Notebook Workflow

The notebook scaffold demonstrates how to connect genotype-specific selection, mean fitness, allele-frequency updates, quantitative trait response, variable-environment selection, time-series screening, condition scoring, and provenance documentation.

Suggested notebook sections:

1. Load selection scenarios.
2. Calculate mean fitness and allele-frequency updates.
3. Compare selection regimes.
4. Estimate quantitative trait selection differential and response.
5. Evaluate variable-environment fitness regimes.
6. Screen time-series allele-frequency change.
7. Score selection condition examples.
8. Record provenance and limitations.

The included `.ipynb` file is intentionally minimal so it can be opened and expanded in JupyterLab or VS Code.
