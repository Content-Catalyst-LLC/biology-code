# Notebook Workflow

The notebook scaffold demonstrates how to connect Hardy-Weinberg expectations, genotype-frequency calculation, expected heterozygosity, selection, mutation, migration, drift, population structure, migration-selection balance, condition scoring, and provenance documentation.

Suggested notebook sections:

1. Load population-genetic scenarios.
2. Calculate Hardy-Weinberg expected genotype frequencies.
3. Simulate selection, mutation, migration, and drift.
4. Process genotype matrices into allele-frequency summaries.
5. Calculate FST-style population structure.
6. Compare migration-selection balance scenarios.
7. Score population-genetic condition examples.
8. Record provenance and limitations.

The included `.ipynb` file is intentionally minimal so it can be opened and expanded in JupyterLab or VS Code.
