# Responsible Use Notes

This repository is educational.

Do not use these scripts for clinical diagnosis, therapeutic targeting, patient stratification, regulatory biotechnology decisions, conservation triage, ecological permitting, environmental-health policy, or automated biological risk assessment.

Responsible life-science machine learning requires:

- domain expertise
- careful problem framing
- documented data provenance
- privacy and governance review for human-derived data
- model validation
- uncertainty communication
- review for bias and underrepresentation
- external validation
- biological review
- institutional oversight where appropriate

A prediction is not a mechanism. A model output is not biological truth. Machine learning should support scientific reasoning, not replace it.
