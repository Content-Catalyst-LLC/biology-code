# Notebook Workflow

The notebook scaffold demonstrates how to connect mutation supply, mutation spectra, sequence distance, nucleotide diversity, structural variation, mutation-selection-drift, novelty condition scoring, and provenance documentation.

Suggested notebook sections:

1. Load mutation spectrum.
2. Estimate mutation supply and Poisson probabilities.
3. Load aligned sequences and calculate pairwise distances.
4. Load genotype site summaries and calculate nucleotide diversity.
5. Load structural variants and calculate simple priority scores.
6. Simulate mutation-selection-drift.
7. Score novelty condition examples.
8. Record provenance and limitations.

The included `.ipynb` file is intentionally minimal so it can be opened and expanded in JupyterLab or VS Code.
