# Ethics and Responsible Use

This repository is educational.

Do not use these scripts for clinical diagnosis, pathology interpretation, patient triage, regulatory medical-device workflows, or automated biological decision-making.

Responsible microscopy image analysis requires:

- biological expertise
- acquisition metadata
- quality-control review
- validation against representative data
- privacy and governance review for human-derived data
- uncertainty communication
- reproducible provenance
- careful distinction between visual appearance and measured evidence

Models and algorithms can support judgment, but they should not replace biological or clinical expertise.
