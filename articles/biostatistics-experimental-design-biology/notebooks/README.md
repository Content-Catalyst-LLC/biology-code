# Notebook Workflow

Suggested notebook sections:

1. Load two-group biological measurement data.
2. Estimate effect size and confidence interval.
3. Generate randomized allocation within blocks.
4. Simulate power across sample sizes.
5. Summarize a blocked design.
6. Build and analyze a factorial design scaffold.
7. Distinguish biological and technical replication.
8. Run bootstrap and permutation-test scaffolds.
9. Inspect assay plate layout balance.
10. Record provenance and limitations.
