# Notebook Workflow

The notebook scaffold demonstrates how to connect pathogen load, immune activity, inflammatory damage, repair, threshold screening, immune-condition scoring, and provenance documentation.

Suggested notebook sections:

1. Load immune scenarios and thresholds.
2. Simulate coupled host-pathogen-immune dynamics.
3. Compare peak pathogen, peak immune, and peak damage.
4. Classify scenarios using illustrative thresholds.
5. Calculate immune-condition scores.
6. Record provenance and limitations.

The included `.ipynb` file is intentionally minimal so it can be opened and expanded in JupyterLab or VS Code.
