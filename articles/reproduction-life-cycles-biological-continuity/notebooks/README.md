# Notebook Workflow

The notebook scaffold demonstrates how to connect life-cycle stages, projection matrices, stable stage distributions, continuity scoring, stress scenarios, and provenance documentation.

Suggested notebook sections:

1. Load the stage matrix and initial vector.
2. Project life-cycle stages through time.
3. Estimate dominant eigenvalue growth.
4. Perturb adult survival and compare lambda.
5. Load life-history traits and calculate continuity scores.
6. Compare environmental-stress scenarios.
7. Record provenance and limitations.

The included `.ipynb` file is intentionally minimal so it can be opened and expanded in JupyterLab or VS Code.
