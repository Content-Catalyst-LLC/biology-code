# Notebook Workflow

The notebook scaffold demonstrates how to connect population scenarios, stochastic simulation, stage-structured projection, sensitivity analysis, metapopulation occupancy, and provenance documentation.

Suggested notebook sections:

1. Load population scenario data.
2. Run stochastic logistic population viability simulations.
3. Estimate extinction and quasi-extinction risk.
4. Load and project a stage-structured matrix model.
5. Compare adult-survival perturbation.
6. Run metapopulation occupancy scenarios.
7. Record provenance and limitations.

The included `.ipynb` file is intentionally minimal so it can be opened and expanded in JupyterLab or VS Code.
