# Methodology Notes

## Purpose

This repository demonstrates a reproducible R-first workflow for biostatistics, ecology, and genomics.

## Biostatistics

The biostatistical workflow includes:

- response summaries by treatment
- linear model with batch adjustment
- logistic regression scaffold
- optional mixed-effects model scaffold
- optional survival-analysis scaffold

## Ecology

The ecological workflow includes:

- species-by-site matrices
- total abundance
- richness
- Shannon diversity
- Bray-Curtis dissimilarity
- principal coordinates ordination scaffold

## Genomics

The genomics workflow includes:

- count matrix
- sample metadata
- library-size summary
- CPM normalization
- log2 fold change
- low-count awareness
- design metadata

## Reproducibility

Each workflow records:

- input data
- script
- output table or figure
- assumptions
- QC criteria
- provenance
- limitations

These examples are educational scaffolds and should be adapted with domain-specific validation for real research.
