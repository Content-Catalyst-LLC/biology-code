# Notebook Workflow

The notebook scaffold demonstrates how to connect microevolutionary allele-frequency change, sequence divergence, macroevolutionary turnover, birth-death screening, evolutionary-scale scoring, and provenance documentation.

Suggested notebook sections:

1. Load population scenarios.
2. Calculate Hardy-Weinberg expectations.
3. Simulate selection, mutation, migration, and drift.
4. Load aligned sequences and calculate distance matrices.
5. Compare clade origination, extinction, turnover, and net diversification.
6. Run birth-death screening scenarios.
7. Record provenance and limitations.

The included `.ipynb` file is intentionally minimal so it can be opened and expanded in JupyterLab or VS Code.
