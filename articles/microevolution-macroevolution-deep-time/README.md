# Microevolution, Macroevolution, and Deep Time

This article repository supports the Biology knowledge-series article:

**Microevolution, Macroevolution, and Deep Time**

The code distribution expands the article's compact R and Python examples into a fuller computational evolutionary-scale workflow. It includes Hardy-Weinberg expectations, deterministic selection, mutation, migration, Wright-Fisher drift, sequence divergence, Jukes-Cantor distance, distance-matrix construction, clade-level turnover, birth-death screening, SQL provenance structures, reproducible data files, and multi-language scientific-computing scaffolding.

## Repository Structure

- `python/` — Wright-Fisher simulation, sequence distance matrices, birth-death screening, and evolutionary-scale summaries
- `r/` — allele-frequency dynamics, sequence divergence, clade turnover, and multi-scale comparison
- `julia/` — population-genetic and macroevolutionary turnover modeling
- `fortran/` — compact allele-frequency and diversification numerical kernels
- `rust/` — safe command-line evolutionary-scale scoring utility
- `go/` — portable evolutionary-scale scenario scoring helper
- `c/` — allele-frequency and birth-death computational kernel
- `cpp/` — comparative evolutionary-scale scenario simulation
- `sql/` — populations, sequences, clade turnover, outputs, and provenance schema
- `docs/` — setup, methodology, and reproducibility notes
- `data/` — small reproducible example datasets
- `notebooks/` — notebook scaffold and workflow notes

## Scientific Focus

The workflows are designed to support transparent evolutionary-scale reasoning:

1. Calculate Hardy-Weinberg genotype expectations.
2. Simulate deterministic and stochastic allele-frequency change.
3. Model selection, mutation, migration, and drift.
4. Calculate sequence divergence and Jukes-Cantor distances.
5. Compare clade-level origination, extinction, turnover, and net diversification.
6. Run simple birth-death Monte Carlo screening.
7. Track data provenance and reproducibility.

These examples are educational scaffolds, not operational phylogenetic, conservation, paleobiological, or genomic models. Real applications require empirical population data, sequence alignments, fossil occurrence data, phylogenetic models, uncertainty analysis, and expert interpretation.
